# EduEvent 🎓  

EduEvent is an IT system designed to support the management of academic educational and research events. The project is being carried out as part of the Software Engineering laboratory during the 2026/2027 academic year.

# Technological Stack. 
Frontend: React   
Backend: Python FastAPI   
Database: PostgreSQL   
Repository: Github   
Task management: GitHub Projects   
Testing: pytests and Postman   
Deployment: Render, Docker   

# Modules
Module 1+8: User management, authorisation and Administration panel    
Module 2: Event management   
Module 3+5: Event catalog, search and filtering plus event calendar and schedule   
Module 4: Participant registration and waiting list   
Module 6: Attendance,   
Module 7: participant confirmations and notifications
